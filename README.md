# HTML, CSS & JavaScript Practical Programs

## 📌 Project Overview

This project is a collection of practical programs created as part of the **Web Technology and Internet Programming** course.

The project focuses on:

* HTML
* CSS
* JavaScript
* DOM Manipulation
* JavaScript Events
* Forms and Validation
* Browser Objects and Features
* Web Storage
* Mini Projects

All programs are organized into separate folders and individual HTML files for easy access and practice.

---

## 🎯 Objectives

The main objectives of this project are to:

* Learn the fundamentals of HTML.
* Create and structure webpages.
* Apply CSS for styling and layouts.
* Understand JavaScript programming.
* Manipulate HTML elements using the DOM.
* Work with JavaScript events.
* Create and validate forms.
* Understand browser objects and browser features.
* Store and manage data using Web Storage.
* Create simple interactive web applications.
* Practice web development concepts through practical programs.

# ▶️ How to Run

### Step 1

Open the project folder in **Visual Studio Code**.

### Step 2

Open:

```text
index.html
```

### Step 3

Run the project using a web browser.

You can also use the **Live Server** extension in Visual Studio Code.

### Step 4

From the home page, select:

```text
HTML Programs
CSS Programs
JavaScript Programs
```

### Step 5

Select any individual program from the respective list.
